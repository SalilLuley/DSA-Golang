## 🛠️ **How to Use This Repository**

1. **Clone the Repository**:

   ```bash
   git clone https://github.com/SalilLuley/DSA-Golang.git
   cd DSA-Golang
   ```

2. **Explore the Code**:
   Navigate to the `solutions/` folder to view individual problem solutions.

3. **Run the Code**:
   Use the following template to run specific solutions. Update `leetcode_75.ProblemFunction()` to the desired problem function:

   ```go
   package main

   import (
       "example.com/leetcode_75"
   )

   func main() {
       // leetcode_75.TwoSum()
       // leetcode_75.Fibonacci()
       // leetcode_75.MergeStrings()
       leetcode_75.GreatestCommonDivisorOfStrings()
   }
   ```

   Run the file using:

   ```bash
   go run main.go
   ```
